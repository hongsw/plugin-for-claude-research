# Block 1: ⛏️ 석기시대 — 체험, 먼저 느껴보기

## 목표
Claude Code가 어떤 일을 할 수 있는지 3가지 데모를 통해 체험하고,
**에이전틱 엔지니어 진화**의 큰 그림을 이해합니다.

> **진화 위치**: 흙집(Block 0)에서 도구를 설치했다면, 이제 석기시대입니다.
> 석기시대 = 직접 명령어를 입력하며 가능성을 느끼는 단계.

## 실행 프로토콜

### Phase A (데모 + 실습 안내)

참조 파일 `references/block1-experience.md`의 EXPLAIN 섹션을 읽고:

**에이전틱 엔지니어 진화 개요**
참조 파일 `references/evolution-chronicle.md`의 EXPLAIN 섹션을 읽고:
- 마인크래프트 진화 연대기를 간략히 소개 (흙집→석기→청동기→...→메타)
- "코딩 아키텍처도 조건문 → 역할 분업 → LLM → RAG로 진화한다"
- 이 학습이 바로 그 진화를 체험하는 과정임을 설명

**데모 1: Skill 실행 체험**
- 사용자에게 현재 프로젝트의 스킬 목록을 보여주세요
- 예시: `/self-learning`이 어떻게 동작하는지 설명
- "하나의 명령어가 복잡한 작업을 자동으로 처리합니다"

**데모 2: 명확화 패턴 (AskUserQuestion)**
- 모호한 요청 vs 명확한 요청의 차이를 보여주세요
- 예: "보고서 써줘" → Claude가 되묻기 → 더 좋은 결과

**데모 3: 직접 질문하기**
- "Claude Code에서 MCP가 뭐야?" 같은 질문을 해보도록 안내
- Claude Code 자체가 가이드 역할을 할 수 있음을 보여주기

참조 파일의 EXECUTE 섹션을 읽고 실습을 안내하세요:
- 데모 2, 3을 직접 실행해보도록 안내

마무리 멘트:
"👆 위 내용을 직접 실행해보세요. 실행이 끝나면 '완료' 또는 '다음'이라고 입력해주세요."

**여기서 STOP.**

### Phase B (퀴즈 + 피드백)

참조 파일 `references/evolution-chronicle.md`의 QUIZ 섹션을 읽고 AskUserQuestion으로 퀴즈:

"이 진화 연대기에서 가장 큰 전환점은?"
- 옵션 1: "if/else에서 역할 분업으로 (구조화)"
- 옵션 2: "하드코딩에서 LLM으로 (지능 추가)"
- 옵션 3: "LLM에서 RAG+메모리로 (학습 능력)"

→ 정답 없음. 각 전환점의 의미를 설명하고, 자신의 프로젝트에서 어떤 전환이 필요한지 생각하도록 안내.
→ Block 2로 이동 안내.
